# 🌍 World Lifetime Analysis - Góc Nhìn Hệ Thống Con Người

## 📊 So Sánh Với Nền Văn Minh Con Người

### **Human Civilization Benchmarks**
```
📈 Rise Phase:     0-200 năm   (Thành lập, mở rộng)
🏔️ Peak Phase:     200-300 năm (Đỉnh cao thịnh vượng)
📉 Decline Phase:  300-450 năm (Suy tàn, khủng hoảng)
💥 Collapse Phase: 450-500 năm (Sụp đổ, diệt vong)
📊 Total Average:  500 năm
```

### **WorldOS Conversion**
```
1 Tick = 5 Years
20 Ticks = 100 năm (Rise)
50 Ticks = 250 năm (Peak)  
100 Ticks = 500 năm (Average Lifetime)
```

## 🔍 Phân Tích Tuổi Thọ World

### **Factors Ảnh Hưởng Đến Tuổi Thọ**

#### **1. Entropy Growth Rate**
```
Normal:     0.02/tick (0.1/năm)
High:       0.04/tick (0.2/năm)  
Critical:   0.08/tick (0.4/năm)
```

#### **2. Character Survival Rate**
```
Healthy:    >80% alive
Stable:     60-80% alive
Declining:  30-60% alive
Critical:   <30% alive
```

#### **3. Lifecycle Phases**
- **Rising**: Entropy <0.3, Survival >80%
- **Peak**: Entropy <0.5, Survival >60%  
- **Declining**: Entropy 0.5-0.8, Survival >30%
- **Collapsing**: Entropy >0.8, Survival <30%

## 🎮 Sử Dụng Lifecycle Analysis

### **Command Line Tools**
```bash

# Dự đoán dài hạn

# So sánh với văn minh con người

# Phân tích chi tiết
php artisan world:lifecycle --world-id=1 --detailed
```
