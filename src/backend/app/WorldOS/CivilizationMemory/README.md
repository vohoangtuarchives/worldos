# Civilization Memory Module
## 📋 Overview
Represents the historical "memory" of a universe. Contains `WorldScarEntity` (trauma from crises) and `WorldMythEntity` (foundational stories/canonized lore).

## 🏗️ Architecture
- **Domain Layer**: Scars and Myths

## 📐 Structure
- `Entities/` - `WorldScarEntity`, `WorldMythEntity`
- `Events/` - `ScarCreated`, `MythEmerged`

## 🔗 Integration
- Both Scars and Myths exert pressure on the timeline, feeding into the **Influence** pipeline (`ScarInfluence`, `MythInfluence`).
- Myths are generated by the **Narrative** module when chapters are canonized in the IP Factory.
